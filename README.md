# Champion Compass App

## Overview
Champion Compass is an Android application designed to assist new players of *League of Legends* in choosing appropriate lanes and easy-to-play champions. The app provides personalized recommendations based on users' responses to a dynamic quiz, aiming to simplify game entry and enhance user satisfaction.

---

## Features
- **Dynamic Quiz**: Determines the user’s preferences and playing style.
- **Personalized Recommendations**: Suggests lanes and champions tailored to user skill level.
- **Real-Time Data Management**: Uses Firebase Realtime Database for data sync.
- **Secure Authentication**: Firebase Authentication ensures a secure experience.
- **Adaptive Content**: Advanced quiz logic for tailored suggestions.
- **Optimized Backend**: Firebase Cloud Functions for real-time backend processes.

---

## Technologies Used
- **Java** – Primary development language
- **XML** – UI design using Android Studio
- **Firebase** – Auth, Realtime DB, and Cloud Functions
